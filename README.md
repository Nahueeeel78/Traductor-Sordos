# Traductor Sordos: "Español simple para ti"

Una herramienta diseñada para facilitar la comprensión lectora y la comunicación de la comunidad sorda, traduciendo o adaptando texto en español complejo a una estructura de **Español Simple** ajustada a sus necesidades lingüísticas.

---

## 🚀 Sobre el proyecto

Para muchas personas sordas, la Lengua de Señas es su primera lengua (L1), mientras que el español escrito actúa como una segunda lengua (L2). La gramática del español escrito convencional puede resultar compleja o ambigua. 

**"Español simple para ti"** simplifica la estructura sintáctica, elimina tecnicismos innecesarios y prioriza el orden visual y directo de las ideas para mejorar la accesibilidad digital y la autonomía en la lectura.

---

## ✨ Características principales

* **Simplificación sintáctica:** Conversión de oraciones complejas y voz pasiva a oraciones cortas en voz activa.
* **Vocabulario accesible:** Sustitución de modismos, metáforas y términos abstractos por sinónimos directos.
* **Estructura visual clara:** Organización de la información en puntos clave y listas para facilitar la lectura rápida.
* **Interfaz amigable:** Diseño accesible pensado para una navegación intuitiva sin distracciones.
